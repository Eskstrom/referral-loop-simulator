# Referral Loop Simulator

## Product brief

A simulation and dashboard for a multi-stage follow-up funnel: flagged case → outreach → referral → appointment → completed follow-up. Users identify leakage and test operational interventions.

## Why this belongs in your portfolio

It translates your Qure.ai referral-loop story into a safe, non-diagnostic product. It shows you understand adoption and outcomes beyond model accuracy.

## MVP

- Synthetic cohort data with funnel timestamps and drop-off reasons.
- Funnel, cohort, and site-level views.
- Intervention simulator for outreach speed, referral capacity, and reminders.
- Recommendation card that names the highest-impact bottleneck.

## Success measures

- Every recommendation links to the metric and assumption behind it.
- A user can compare baseline versus simulated intervention outcomes.

## Suggested stack

Python, Pandas, Streamlit or React, SQLite.

## Guardrails

Use fictional data and make clear it is an operations simulator, not clinical advice.
